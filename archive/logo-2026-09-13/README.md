# Logo-Archiv — Stand vor der Umstellung (13.09.2026)

Hier liegen die **bisherigen** Logo-/Icon-Dateien der MDU, gesichert bevor das
neue ovale Logo übernommen wurde. Zum Zurückkehren einfach zurückkopieren:

    cp archive/logo-2026-09-13/mdu-logo.webp   public/mdu-logo.webp
    cp archive/logo-2026-09-13/favicon.ico     app/favicon.ico
    cp archive/logo-2026-09-13/icon.png        app/icon.png
    cp archive/logo-2026-09-13/apple-icon.png  app/apple-icon.png

Danach `npm run build` und committen/pushen.

Verwendet wird `public/mdu-logo.webp` in Kopfzeile, Fußzeile, Admin-/Login-
Shell, Coming-Soon, Spielbericht-Vorlage, News-Share-Bild und als OG-Logo.
`favicon.ico` / `icon.png` / `apple-icon.png` sind die Tab-/App-Symbole.
